# 合同审批管理

我们要做一个合同审批管理功能，给销售、销售主管、法务、财务和管理员使用。

销售创建合同，填写客户名称、合同金额、合同周期、回款方式、合同附件和特殊条款说明。合同金额超过 50 万元时必须经过销售主管、法务和财务审批；合同金额不超过 50 万元时只需要销售主管和法务审批。

销售主管主要判断客户、金额、折扣和销售政策是否合理。法务主要检查合同条款、附件完整性和风险条款。财务主要检查开票信息、回款计划和付款条件。

审批过程中，审批人可以通过、驳回或退回修改。退回修改后销售可以重新提交，重新提交后需要重新进入审批流。审批完成后合同状态变为已生效。被驳回的合同不能继续审批，但可以复制为新合同。

管理员可以配置合同类型、审批金额阈值、审批角色和必填附件规则。不同角色看到的列表操作不同：销售只能查看和维护自己创建的合同，主管可以查看团队合同，法务和财务只看到待自己处理或已处理的合同，管理员可以查看全部合同和配置规则。

列表页需要支持按合同编号、客户名称、合同状态、合同金额范围、创建人、提交时间和当前审批节点筛选。详情页需要展示合同基本信息、附件、审批流转记录、审批意见和风险提示。

希望生成一个可评审的 B 端原型、PRD、测试用例、流程图和一致性检查报告。
