# B 端 UX 质量规则

本文件从 UI/UX Pro Max 的 Quick Reference 提取并适配 B 端企业应用场景，作为 Gate 4 审查和原型自查的 UX 质量标准。

## 1. 无障碍（Accessibility）— 必须

| 规则 | 标准 | 违反示例 |
|------|------|----------|
| 色彩对比度 | 正文 4.5:1，大文字 3:1 | 浅灰文字 #94A3B8 在白色背景上（仅 2.8:1） |
| 键盘导航 | Tab 顺序与视觉顺序一致，所有交互元素可达 | 表格操作按钮无法 Tab 到达 |
| ARIA 标签 | 图标按钮必须有 aria-label | 只有图标的删除按钮无文字标签 |
| 标题层级 | h1→h6 顺序递进，不跳级 | 页面直接从 h1 跳到 h3 |
| 焦点可见 | 交互元素有 2-4px 焦点环 | 移除 outline 无替代方案 |
| 不仅靠颜色 | 不能仅用颜色传达信息（加图标/文字） | 红色=错误、绿色=成功无文字说明 |

## 2. Web 交互 — 必须

| 规则 | 标准 | 违反示例 |
|------|------|----------|
| 点击区域 | 最小 32×32px，推荐 38×38px | 表格行内操作图标仅 16px |
| cursor-pointer | 可点击元素必须有 cursor: pointer | 可点击的卡片无指针样式 |
| Hover 反馈 | 150-300ms 过渡动画 | 表格行无 hover 高亮 |
| 点击反馈 | 按钮点击有 active 状态（缩放/变色） | 按钮点击无视觉反馈 |
| Loading 状态 | 异步操作期间按钮禁用 + 显示 spinner | 提交按钮可重复点击 |
| 错误反馈 | 错误信息在问题字段附近 | 错误只显示在页面顶部 |
| 禁用状态 | 减少透明度 (0.38-0.5) + cursor: not-allowed | 禁用按钮看起来可点击 |

## 3. 表单 UX — 必须（B 端核心）

| 规则 | 标准 | 违反示例 |
|------|------|----------|
| 可见标签 | 每个输入框有可见 label（不仅 placeholder） | placeholder 作为唯一标签 |
| 必填标记 | 必填字段标星号 * | 必填字段无标记 |
| 错误定位 | 错误信息显示在对应字段下方 | 所有错误堆积在表单顶部 |
| 行内校验 | 失焦时校验，非每次按键 | 每次输入都报错 |
| Helper 文本 | 复杂输入框下方有持久帮助文本 | 只有 placeholder 无帮助 |
| 渐进披露 | 复杂选项逐步展开，不一次全展示 | 20 个字段一次性全显示 |
| 自动聚焦 | 提交错误后自动聚焦第一个错误字段 | 错误后焦点停留在提交按钮 |
| 表单自动保存 | 长表单自动保存草稿 | 填写 10 分钟后误操作全丢 |
| 密码切换 | 密码字段提供显示/隐藏切换 | 密码字段无切换按钮 |
| 语义化输入类型 | email/tel/number 使用语义类型 | 电话号码用 text 输入 |
| 多步骤进度 | 多步表单显示步骤指示器 | 5 步表单无进度提示 |
| 只读区分 | 只读状态视觉上与禁用不同 | 只读字段看起来像禁用 |

## 4. 布局与响应式 — 必须

| 规则 | 标准 | 违反示例 |
|------|------|----------|
| 响应式断点 | 768 / 1024 / 1280 / 1440 | 仅适配 1440px 宽屏 |
| 移动端字号 | 正文最小 16px（避免 iOS 自动缩放） | 移动端正文 12px |
| 水平滚动 | 移动端不允许水平滚动 | 表格在手机上溢出 |
| 间距系统 | 4px 基础网格，所有间距为 4 的倍数 | 使用 13px、17px 等奇数间距 |
| 内容宽度 | 桌面端最大宽度 1280px 居中 | 内容撑满 1920px 屏幕 |
| z-index 管理 | 定义层级体系 (0/10/20/40/100/1000) | z-index: 99999 到处都是 |
| 固定元素偏移 | 固定导航/底栏为内容留出安全间距 | 内容被固定底栏遮挡 |

## 5. 排版与色彩 — 建议

| 规则 | 标准 | 违反示例 |
|------|------|----------|
| 行高 | 正文 1.5-1.75 | 行高 1.0 导致文字挤在一起 |
| 行宽 | 60-75 字符/行 | 全宽段落在大屏幕上一行 200 字 |
| 字体配对 | 标题/正文字体风格协调 | 标题用衬线体正文用无衬线体 |
| 字号比例 | 使用系统字号比例尺 | 随意设置 11px/13px/15px |
| 语义化色彩 | 使用 Token 语义色（primary/error/surface），不用裸 hex | 组件中写死 #2563EB |
| 暗色模式 | 暗色模式用去饱和/浅色调变体，非反色 | 简单反转所有颜色 |
| 数字等宽 | 数据列使用等宽数字 | 数字列宽度跳动 |

## 6. 导航模式 — 必须（B 端）

| 规则 | 标准 | 违反示例 |
|------|------|----------|
| 侧边栏导航 | B 端首选侧边栏，二级用面包屑 | 混用 Tab + Sidebar + Bottom Nav |
| 当前位置高亮 | 当前页面在导航中视觉高亮 | 无选中态 |
| 面包屑 | 3+ 层级深度使用面包屑 | 5 级页面无面包屑 |
| 返回行为 | 返回保持之前的滚动/筛选/输入状态 | 返回后筛选条件丢失 |
| 标签页记忆 | Tab 切换保持各 Tab 状态 | 切 Tab 后表单数据丢失 |
| 溢出菜单 | 操作过多时用"更多"菜单 | 挤放 10 个按钮 |
| 深度链接 | 关键页面支持 URL 直达 | 审批详情无法分享链接 |
| 导航一致性 | 所有页面导航位置不变 | 某些页面导航消失 |

## 7. 表格 UX — 必须（B 端核心）

| 规则 | 标准 | 违反示例 |
|------|------|----------|
| 列排序 | 支持点击表头排序 + aria-sort | 数据列不可排序 |
| 筛选 | 提供筛选器（搜索/下拉/日期范围） | 100 行数据无筛选 |
| 分页 | 大数据集分页，显示总数和当前位置 | 一次性加载 1000 行 |
| 列宽 | 重要列可拖拽调整宽度 | 列宽固定无法调整 |
| 固定列 | 首列/操作列固定，横向滚动时可见 | 滚动后看不到操作按钮 |
| 空状态 | 无数据时显示引导信息 + 操作入口 | 空白表格无提示 |
| 加载状态 | 数据加载时显示骨架屏 | 加载时显示空表格 |
| 选择反馈 | 复选框选中后显示批量操作栏 | 选中后无操作入口 |
| 行悬停 | 行悬停有背景高亮 | 表格行无交互反馈 |

## 8. 批量操作 — 必须（B 端核心）

| 规则 | 标准 | 违反示例 |
|------|------|----------|
| 选择指示 | 选中数量明确显示（"已选 5 项"） | 不知道选了多少 |
| 批量操作栏 | 选中后浮出操作栏 | 需要逐个操作 |
| 全选 | 支持全选/取消全选 | 只能逐个选择 |
| 跨页选择 | 分页场景支持跨页选择 | 换页后选择丢失 |
| 进度指示 | 批量操作显示进度 | 批量删除 100 条无进度 |
| 撤销 | 危险批量操作提供撤销 | 批量删除不可撤销 |

## 9. 审批流 UX — 必须（B 端核心）

| 规则 | 标准 | 违反示例 |
|------|------|----------|
| 状态可视化 | 审批状态用颜色+文字+图标 | 仅文字"审批中" |
| 操作历史 | 完整展示审批流转记录 | 只显示当前状态 |
| 驳回原因 | 驳回时必须填写原因 | 驳回无原因 |
| 待办提示 | 待审批数量在导航中 badge 提示 | 有待审批但无提示 |
| 操作确认 | 通过/驳回前二次确认 | 一键驳回无确认 |
| 超时提醒 | 审批超时有提醒机制 | 超时 7 天无任何提示 |

## 10. 动画 — 建议

| 规则 | 标准 | 违反示例 |
|------|------|----------|
| 时长 | 微交互 150-300ms，复杂过渡 ≤400ms | 动画 >500ms |
| 性能 | 只动画 transform/opacity | 动画 width/height 触发重排 |
| 缓动 | 进入 ease-out，退出 ease-in | 使用 linear 缓动 |
| 减少动画 | 尊重 prefers-reduced-motion | 无视系统减少动画设置 |
| 出场比入场快 | 出场动画 = 入场的 60-70% | 出场和入场一样慢 |

## 11. 图表与数据 — 建议

| 规则 | 标准 | 违反示例 |
|------|------|----------|
| 图表类型匹配 | 趋势→折线，对比→柱状，占比→饼图 | 用饼图展示时间趋势 |
| 可访问色板 | 避免仅红绿配色（色盲） | 红绿配色无替代方案 |
| 图例可见 | 图例始终显示，不被截断 | 图例在滚动区域外 |
| 悬停详情 | 悬停/点击显示精确数据 | 无 tooltip |
| 空数据状态 | 无数据时显示引导 | 空白图表 |
| 数据表格替代 | 提供图表的表格视图 | 只有图表无表格 |

## 审查优先级

Gate 4 审查时按以下优先级检查：

1. **必须修复（Critical）**：无障碍对比度、键盘导航、表单标签可见性、错误定位、表格空状态
2. **建议修复（Warning）**：响应式断点、动画时长、导航一致性、批量操作完整性
3. **优化建议（Suggestion）**：排版微调、动画缓动、图表可访问性、数字等宽
