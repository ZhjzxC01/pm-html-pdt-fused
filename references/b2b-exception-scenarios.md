# B 端异常场景标准库

用途：PRD 和原型生成时必须覆盖的异常场景清单。每个异常场景对应具体的处理方式和用户体验。

## 异常场景分类

### 1. 数据不存在

用户访问了已删除或不存在的业务数据。

| 场景 | 触发条件 | 处理方式 |
|------|----------|----------|
| 访问已删除单据 | 通过 URL 或书签访问已删除数据 | 404 页面 + "该数据已删除"提示 + 返回列表按钮 |
| 列表中点击已删除行 | 列表加载后数据被他人删除 | 提示"数据已不存在" + 自动刷新列表 |
| 引用已删除主数据 | 单据引用的客户/供应商已停用 | 展示停用标记 + 不可新建引用 |

**原型要求：** 每个详情页必须有 404 状态页面。

### 2. 无权限

用户尝试访问没有权限的功能或数据。

| 场景 | 触发条件 | 处理方式 |
|------|----------|----------|
| 无功能权限 | 普通用户访问管理页面 | 403 页面 + "请联系管理员开通权限" |
| 无数据权限 | 用户查看他人数据 | 403 页面 + "无权查看该数据" |
| 按钮灰色不可用 | 用户无权执行某操作 | 按钮置灰 + hover 提示"无权限" |
| URL 直接访问 | 用户手动输入无权访问的 URL | 重定向到 403 页面 |

**原型要求：** 每个页面必须有无权限状态页面。

### 3. 并发冲突

多用户同时操作同一条数据。

| 场景 | 触发条件 | 处理方式 |
|------|----------|----------|
| 同时编辑 | 两人同时打开同一单据编辑 | 后保存者提示"数据已被 XX 修改于 XX 时间" + 提供"覆盖保存"和"放弃修改"选项 |
| 同时审批 | 两人同时审批同一单据 | 后操作者提示"该单据已被 XX 处理" + 自动刷新状态 |
| 状态变更冲突 | 操作时单据状态已变更 | 提示"当前状态已变更为 XX" + 刷新页面 |

**原型要求：** 审批页面必须有并发冲突提示状态。

### 4. 状态冲突

操作与当前业务状态不匹配。

| 场景 | 触发条件 | 处理方式 |
|------|----------|----------|
| 已审批再次审批 | 审批人尝试审批已处理的单据 | 提示"该单据已处理，当前状态：XX" |
| 已提交再次提交 | 用户快速双击提交按钮 | 按钮防抖（提交后禁用）+ loading 状态 |
| 非草稿状态编辑 | 用户尝试编辑已提交的单据 | 编辑按钮置灰 + 提示"仅草稿状态可编辑" |
| 终态操作 | 用户尝试操作已完成/已驳回的单据 | 操作按钮不展示 |

**原型要求：** 每个详情页必须展示当前状态对应的可用操作。

### 5. 网络异常

网络不稳定或接口超时。

| 场景 | 触发条件 | 处理方式 |
|------|----------|----------|
| 提交时断网 | 表单提交时网络中断 | 保留表单数据 + "网络异常，请检查网络后重试" + 重试按钮 |
| 页面加载失败 | 列表/详情页加载超时 | 错误页 + "加载失败" + 重试按钮 |
| 文件上传失败 | 附件上传时网络中断 | 保留已填数据 + "上传失败，请重试" + 支持断点续传 |
| 接口超时 | 导出大数据量超时 | 转为异导出 + 完成后通知下载 |

**原型要求：** 表单页面必须有网络异常保留数据的机制。

### 6. 格式校验

用户输入的数据不符合格式要求。

| 场景 | 触发条件 | 处理方式 |
|------|----------|----------|
| 必填字段为空 | 漏填提交 | 字段标红 + 错误提示"此项为必填" |
| 格式错误 | 金额填了文字、手机号格式不对 | 实时校验 + 错误提示 + 提交按钮禁用 |
| 超出范围 | 金额超过上限、文本超出长度限制 | 实时提示 + 限制输入 |
| 联动校验失败 | 结束日期早于开始日期 | 校验提示"结束日期不能早于开始日期" |
| 文件类型/大小错误 | 上传不支持的文件格式 | 提示"仅支持 jpg/png/pdf，单文件不超过 10MB" |

**原型要求：** 所有表单字段必须有对应的校验状态（默认态、校验通过、校验失败）。

### 7. 数据过期

用户长时间未操作后数据已变更。

| 场景 | 触发条件 | 处理方式 |
|------|----------|----------|
| 列表数据过期 | 用户长时间未刷新列表 | 操作时提示"数据可能已过期，建议刷新" + 刷新按钮 |
| Session 过期 | 用户长时间未操作 | 跳转登录页 + 保留之前操作的 URL（登录后可跳回） |
| Token 过期 | API Token 超时 | 自动刷新 Token（如有 RefreshToken）或跳转登录 |

### 8. 批量操作异常

批量操作中部分失败。

| 场景 | 触发条件 | 处理方式 |
|------|----------|----------|
| 部分成功 | 10 条批量审批，7 成功 3 失败 | 结果汇总弹窗："成功 7 条，失败 3 条" + 失败原因列表 |
| 全部失败 | 批量导入所有行校验不通过 | 提示"所有数据校验失败" + 错误报告下载 |
| 选中项状态不一致 | 批量审批时部分已审批 | 提示"已自动排除 3 条已处理记录，将处理剩余 7 条" |
| 超过数量限制 | 单次选择超过最大条数 | 提示"单次最多操作 XX 条，请减少选中数量" |

### 9. 导入异常

Excel/CSV 导入过程中的异常。

| 场景 | 触发条件 | 处理方式 |
|------|----------|----------|
| 格式错误行 | Excel 中有格式错误的数据 | 错误行标红 + 错误原因 + 下载错误报告 |
| 缺少必填列 | Excel 模板缺少必填列 | 提示"缺少必填列：XX" + 提供正确模板下载 |
| 重复数据 | 导入的数据与已有数据重复 | 根据策略处理：跳过（默认）/ 覆盖 / 报错 |
| 文件过大 | 上传文件超过大小限制 | 提示"文件大小超过限制（最大 XX MB）" |
| 编码问题 | CSV 文件编码不是 UTF-8 | 自动检测编码或提示"请使用 UTF-8 编码保存" |

### 10. 异步任务异常

后台异步任务（导出、导入、批量处理）的异常。

| 场景 | 触发条件 | 处理方式 |
|------|----------|----------|
| 任务排队中 | 大批量操作需要排队 | 展示排队位置和预计等待时间 |
| 任务执行失败 | 后台处理过程中出错 | 站内消息通知 + 失败原因 + 重试按钮 |
| 任务结果过期 | 导出文件保留期限已过 | 提示"文件已过期，请重新导出" |

## 异常场景覆盖检查清单

PRD 和原型生成后，使用以下清单检查异常场景覆盖：

### 每个页面必须覆盖

- [ ] 加载状态（骨架屏 / loading）
- [ ] 空状态（无数据时的引导）
- [ ] 错误状态（加载失败时的重试）
- [ ] 无权限状态（403）

### 每个表单必须覆盖

- [ ] 必填字段校验
- [ ] 格式校验（类型、长度、范围）
- [ ] 联动校验（字段间依赖关系）
- [ ] 提交防抖（防重复提交）
- [ ] 网络异常数据保留

### 每个审批流必须覆盖

- [ ] 并发审批冲突
- [ ] 状态变更冲突
- [ ] 审批人无权限（角色变更后）
- [ ] 撤回时机限制

### 每个列表页必须覆盖

- [ ] 空列表引导
- [ ] 筛选无结果
- [ ] 批量操作部分失败
- [ ] 分页异常（页码超出范围）

### 每个导入导出必须覆盖

- [ ] 文件格式/大小错误
- [ ] 数据校验失败
- [ ] 重复数据处理
- [ ] 大数据量异步处理
- [ ] 导出文件过期
