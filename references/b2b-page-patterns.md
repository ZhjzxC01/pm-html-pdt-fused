# B 端页面模式库

用途：原型生成时参考的标准页面模式，确保覆盖 B 端高频页面类型。

## 已覆盖的页面模式

以下页面模式已内置在原型生成器中：

### 列表页 + 筛选 + 分页

标准列表页，包含搜索栏、筛选条件、表格、分页。

- 页面目标：浏览、搜索、定位业务数据
- 核心模块：筛选区、操作按钮区、数据表格、分页器
- 角色差异：不同角色看到不同数据范围（数据权限）和不同操作按钮（功能权限）
- 空状态：无数据时显示引导文案和"新建"按钮
- 必须包含：加载骨架屏、空状态、网络异常状态

### 详情页 + 操作记录

单条业务数据的完整信息展示。

- 页面目标：查看业务数据详情、执行后续操作
- 核心模块：基本信息区、关联数据区、操作记录/时间线
- 角色差异：不同角色看到不同操作按钮
- 必须包含：404 状态（数据不存在）、无权限状态

### 新建/编辑表单页

业务数据的创建和编辑。

- 页面目标：录入或修改业务数据
- 核心模块：表单字段区、提交/取消按钮
- 交互规则：必填校验、格式校验、联动校验、条件显隐
- 必须包含：表单数据保留（网络异常时不丢失）、提交防抖

### 审批处理页

审批人处理待审批单据。

- 页面目标：审批人查看单据并做出审批决定
- 核心模块：单据详情展示区、审批操作区（通过/驳回/转交）
- 角色差异：不同审批节点看到不同操作按钮
- 必须包含：审批意见输入框（驳回时必填）、并发冲突提示

## 需补充的页面模式

以下页面模式在 B 端高频使用，原型生成器需要支持：

### 看板视图（Kanban）

拖拽式状态管理，适用于任务管理、工单管理、CRM 等场景。

- 页面目标：直观查看各状态下的数据分布，支持拖拽改变状态
- 核心模块：状态列（如待处理/处理中/已完成）、卡片列表、拖拽交互
- 每个卡片展示：标题、负责人、优先级、关键字段（如金额、截止日期）
- 交互规则：拖拽触发状态流转，需校验流转权限
- 与列表页关系：同一数据支持切换"列表视图"和"看板视图"
- 空状态：空列显示"拖拽卡片到此列"
- 原型标识：`data-page-type="kanban"`

### 树形结构页

适用于组织架构、分类管理、菜单管理、地区管理等层级数据。

- 页面目标：管理和浏览层级结构数据
- 核心模块：左侧树形导航、右侧详情/编辑区
- 交互规则：展开/折叠节点、右键菜单（新增子节点/编辑/删除/移动）
- 约束规则：删除有子节点的节点时，需确认是否级联删除或禁止删除
- 拖拽规则：支持拖拽调整节点顺序和层级
- 空状态：根节点为空时显示"创建顶级节点"
- 原型标识：`data-page-type="tree"`

### 多 Tab 详情页

适用于复杂对象详情，信息量大需要分区展示。

- 页面目标：分区域展示复杂业务对象的完整信息
- 核心模块：Tab 导航栏、各 Tab 内容区
- Tab 类型：
  - 基本信息 Tab：核心字段展示和编辑
  - 关联数据 Tab：与该对象关联的子数据列表（如合同下的付款记录）
  - 操作记录 Tab：操作日志和状态变更历史
  - 附件 Tab：文件上传和管理
- 交互规则：切换 Tab 不刷新页面、未保存修改切换 Tab 时提示
- 懒加载：非首屏 Tab 按需加载
- 原型标识：`data-page-type="tab-detail"`

### 步骤表单（Stepper）

适用于复杂表单需要分步填写的场景。

- 页面目标：引导用户分步完成复杂表单的填写
- 核心模块：步骤指示器、当前步骤表单区、上一步/下一步/提交按钮
- 步骤指示器：展示总步骤数、当前步骤、已完成步骤
- 交互规则：
  - 每步完成后校验当前步骤字段
  - 允许返回上一步修改（已填数据保留）
  - 最后一步提交前全量校验
  - 步骤间有依赖时，修改上游步骤需清空下游已填数据
- 必须包含：进度保存（中断后可继续）
- 原型标识：`data-page-type="stepper"`

### 数据对比页

适用于版本对比、变更前后对比、审核对比等场景。

- 页面目标：并排展示两个版本的数据差异
- 核心模块：左右对比面板、差异高亮
- 差异类型：新增（绿色）、删除（红色）、修改（黄色）
- 适用场景：合同变更审批（变更前后对比）、数据导入预览（导入前后对比）
- 原型标识：`data-page-type="diff"`

### 仪表盘/看板

适用于数据统计展示、运营监控。

- 页面目标：一屏展示关键业务指标和趋势
- 核心模块：统计卡片区、图表区（折线/柱状/饼图）、快捷操作区
- 布局规则：重要指标放左上、支持自定义布局
- 数据刷新：实时或定时刷新
- 交互规则：点击统计卡片可下钻到明细列表
- 原型标识：`data-page-type="dashboard"`

### 配置页面

适用于系统设置、规则配置、参数管理。

- 页面目标：管理系统配置项
- 核心模块：配置分组（左侧导航或顶部 Tab）、配置项表单
- 配置项类型：开关、输入框、下拉选择、级联选择、富文本
- 交互规则：修改后需点击"保存"生效、危险配置需二次确认
- 审计要求：配置变更必须记录操作日志
- 原型标识：`data-page-type="config"`

## 页面模式选择规则

当原型生成器需要决定使用哪种页面模式时，参考以下规则：

| 需求特征 | 推荐页面模式 |
|----------|-------------|
| 数据列表 + 搜索筛选 | 列表页 |
| 单条数据完整信息 | 详情页 |
| 数据创建/编辑 | 表单页 |
| 审批流程 | 审批处理页 |
| 多状态拖拽管理 | 看板视图 |
| 层级数据管理 | 树形结构页 |
| 复杂对象多维信息 | 多 Tab 详情页 |
| 复杂表单分步填写 | 步骤表单 |
| 版本/数据对比 | 数据对比页 |
| 数据统计展示 | 仪表盘 |
| 系统参数管理 | 配置页面 |
